How a project is considered

  1. A project or enterprise is proposed.
  2. It is reviewed against {{ org_short }}'s objectives.
  3. A financial review checks the budget and funding needed.
  4. A risk assessment considers what could go wrong.
  5. Only an approved project can receive funding, and only from available funds.
  6. Funded projects report progress, expenses and revenue, which are verified and published.

Not every project will receive funding, and no project is guaranteed to make a profit.
